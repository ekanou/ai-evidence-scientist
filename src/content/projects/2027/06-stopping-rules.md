**In eight weeks.** Compare three kinds of stopping rule on the same runs: the agent's own confidence, statistical rules that target a recall level, and rules that stop once the pooled estimate stops moving. Report recall, cost and conclusion stability for each. Agent confidence is known to be a weak signal once retrieved text is in context ([Soudani et al., 2025](#ref-soudani-2025)).

**As a thesis.** Stopping rules that state the risk of a changed conclusion, not only a recall target.

**Starting data.** Existing technology-assisted review collections for screening; review/update pairs for conclusion stability.
