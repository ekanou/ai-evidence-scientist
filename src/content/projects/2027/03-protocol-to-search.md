title: From protocol to search strategy

question: Given only a protocol, how well can an agent search several sources, and where does it fall short of a published search strategy?
background: Information retrieval, NLP
---

**In eight weeks.** Build agents that turn a protocol into queries for bibliographic databases and trial registries. Compare their queries with the published search strategies, and measure which included studies each one finds.

**As a thesis.** Iterative search: let the agent reformulate from what it has already found, under a fixed query budget.

**Starting data.** Published reviews that report their search strategies and included studies; existing technology-assisted review collections ([Kanoulas et al., 2017](#ref-kanoulas-2017), [2018](#ref-kanoulas-2018), [2019](#ref-kanoulas-2019)).
